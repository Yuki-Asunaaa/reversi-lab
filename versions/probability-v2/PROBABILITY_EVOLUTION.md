# 全局获胜概率算法：V1 → V2

本文记录实现方法及留档位置，供后续实验报告使用。本轮按要求只优化并训练，不进行第三步的独立准确性验证。

## 版本区分

这里的 V1/V2 是**概率估计器版本**，与棋手算法 V1/V2/V3 是两套编号。概率 V2 使用棋手 V3 的搜索能力分析局面，但不会改变任一棋手算法。

## 旧版概率 V1（完整留档）

位置：`versions/probability-v1/`。

- `reversi/analysis.py`：统一三层 Alpha-Beta 分析；≤10 空格尝试完整求解。
- `reversi/search.py`、`board.py`：当时使用的搜索和评估函数。
- `tools/calibrate.py`：旧训练程序。
- `data/calibration_games.json`：128 盘三层 Alpha-Beta 自对弈原始数据。
- `data/calibration.json`：旧模型权重、96 盘训练 / 32 盘保留验证及原有指标。
- `README.md`、`web/`：旧说明与展示方式。
- `manifest.json`：文件 SHA-256，便于核对留档未被修改。

旧方法把黑方视角评分、阶段及交互项送入三分类 Softmax，输出黑胜／和棋／白胜。模型通过黑白镜像保证颜色对称。三层评分较浅，校准对象又只有三层 Alpha-Beta 自对弈；双方算法与时间差异未进入模型。因此旧模型更适合参考棋力下的趋势，不能直接当成 V3 对 MCTS 或人类对 AI 的真实胜率。

旧验证 Brier 约 0.312，类别比例基线约 0.504，对数损失约 0.507。它们只描述旧模型在旧验证集的结果，**不是新版准确性指标**，也不能转成百分比准确率。

如需复现旧算法，请先复制整个 `versions/probability-v1/` 到单独目录，再运行其中的训练脚本；不要在留档原件中覆盖权重或原始数据。

## 新版概率 V2

### 1. 更深入的统一局面分析

使用 V3 的 PVS、置换表与动态评估，对所有棋手组合采用同一套**五层目标分析**。正常局面最多用 0.6 秒，保留已完整完成的深度；预算不足时记录实际深度，不伪称完成五层。

同时保留相邻完成层的评分差异。它是“分析是否稳定”的输入特征，不等同于统计置信区间，也不保证某次搜索没有漏掉战术。

剩余 ≤14 格时，用总分析预算剩余部分继续尝试精确残局求解，总预算默认 1.2 秒。解出后单独显示“双方最佳应对下的结果”，不把它伪装成实际棋手的必胜概率。实际终局才显示实际 100% 结果。

### 2. 将双方对局条件纳入模型

模型使用 24 个特征：

- 局面评分、阶段、评分与阶段的交互；
- 评分绝对值、相邻层评分分歧、实际完成深度；
- 双方时限的对数均值与差值，以及时限差和阶段的交互；
- 六种算法的黑白身份差，以及这些差异与阶段的交互。

不同配置下，同一局面可以有不同的估计。算法因素随阶段变化，使模型可以学习“前期棋力差仍有较多发挥空间，终盘更受具体局面制约”的关系。特征符号按黑白互换分为偶对称和奇对称，权重显式约束，防止人为颜色偏置。

分析器取得配置快照。若配置在分析阶段改变，重新分析；已经开始的思考回合仍保持原设置，新设置在后续回合使用。

### 3. 使用多算法实际结果重新拟合

- 复用前次 188 盘多算法对局，不沿用它们的旧局面评分。
- 补充 16 盘非对称时限训练对局：Alpha-Beta、V3、Minimax、MCTS 分别在 0.05 / 0.2 秒下同算法对战、交换黑白，用于学习时限差异。
- 每六个记录步抽取一个局面，用新版五层分析器重算评分与层间分歧。本次共 204 盘、3,426 个含镜像训练样本。
- 已由分析器解出的局面不混入普通概率拟合；不足三层的样本不采用。
- 每盘棋总训练权重相同，避免长棋局凭样本多而支配拟合；增加黑白镜像。
- 自行实现 Softmax、Adam 和 L2 正则化。正则化用于限制小数据下的极端参数，不代表经过验证的概率校准效果。
- 所有可用数据都用于训练；不另划验证集、不计算准确率、Brier、可靠性分桶或任何“优化提升百分比”。

某些历史文件名含 `validation`，因为它们曾用于验证**棋手棋力**。本次它们是**概率模型的训练输入**，不能再拿这些对局证明新版概率准确。

### 4. 明确无法从数据得出的信息

**人类水平未知：**PvE 中暂以“人类使用与对面 AI 相同策略和时限”作为参考条件，并在界面注明。它不是对用户棋力的判断，也没有根据一次输赢自动认定用户更强或更弱。

**训练时限覆盖有限：**当前训练范围是 0.05～0.5 秒。超出范围的设置按边界输入并明确提示；不能声称已经学到了 3、10、30 秒下的真实胜率，也不会用没有数据支持的外推公式给长思考时间任意加分。

**配对覆盖有限：**若某组算法未直接用于训练，会显示提示。模型仍可组合已学特征给参考值，但这不等于已证明能准确泛化。

**低概率不等于必败：**新版不会因为用户报告“10% 仍获胜”就强行抬高所有低概率。10% 应允许逆转；是否真的接近 10%，只有后续独立验证才能回答。本轮没有执行该验证。

## 文件与运行

| 文件 | 用途 |
| --- | --- |
| `reversi/analysis.py` | 五层分析、残局求解、配置快照及状态标签 |
| `reversi/probability.py` | 新特征定义、对称规则、Softmax 推断 |
| `tools/train_probability.py` | 补充训练对局、重算局面特征、仅训练权重 |
| `tools/calibrate.py` | 新训练程序的兼容入口 |
| `data/probability_v2_training_games.json` | 16 盘新增训练棋谱 |
| `data/probability_v2_samples.json` | 新分析器重算后的训练局面、来源哈希 |
| `data/probability_v2.json` | 新权重、训练信息、`validation: null` |
| `versions/probability-v1/` | 旧算法完整留档 |
| `versions/probability-v2/` | 本次新算法与权重快照 |

```bash
# 补充训练数据若已存在会复用；评分记录在来源和评分器哈希一致时可断点续算
python3 tools/train_probability.py
# 复用已经生成的新特征，仅重新拟合权重
python3 tools/train_probability.py --reuse
```

以上命令只有训练流程，没有独立准确性验证。新版界面明确标记“V2 估计 · 未验证”，旧版验证数字不再出现在新版模型卡片中。
