规则、搜索、计时和概率，各自有清晰的定义。

01 / RULES

经典黑白棋规则

黑方 E4、D5，白方 D4、E5，黑方先行。每次在空格落子，必须沿横、竖、斜方向夹住至少一枚对手棋子，所有被夹住的棋子均翻转。

有合法着法必须落子；无合法着法自动跳过。棋盘填满或双方都无合法落点时结束，棋子更多者获胜；相等为和棋。运行中的单步超过 60 秒判负。

02 / SEARCH

三种基线，三代改进

Minimax 与 Alpha-Beta 使用相同评估函数、迭代加深与走法排序。Alpha-Beta 额外剪去不影响最佳决策的分支。

MCTS 自行实现 UCT 选择、扩展、终局模拟和回传。模拟优先角点并避开空角附近危险格。混合 AI 在空格 ≤12 时切换 Alpha-Beta，其余时候使用相同 MCTS。

V1 保留阶段切换；V2 改用 PVS、置换表和历史排序；V3 再加入动态角邻格评估、潜在行动力和愿望窗口。详细方法与实测结果见“算法进化”。

03 / PROBABILITY

估算胜率有参考条件

主胜率由统一三层 Alpha-Beta 分析器提供评分，再由项目自身自对弈数据拟合黑胜、和棋、白胜三分类概率。参考对象是三层 Alpha-Beta 的对弈水平。

校准按整盘划分训练和验证，包含随机合法开局与黑白镜像样本；同一盘棋不会跨集合。未完成分析不显示虚构百分比。

已完全搜索的残局另行显示双方最佳应对下的结论。它不同于未知人类玩家的实际获胜概率。

04 / TIMING

清楚区分两种时间

对局中的本步用时包括 AI 进程启动与协调开销；搜索观察显示算法本身的计算时间。每回合前的统一分析不计入落子时间，动画与界面保持响应。

机机对局点击暂停，会在当前 AI 落子后暂停；人类回合立即暂停并冻结计时。更改算法和档位从下一回合生效。批量实验完全不运行胜率分析。

A TRACEABLE EVOLUTION

保留每一次尝试。

从阶段切换，到搜索复用，再到局面理解。用同预算对局检验改进。

V1 / 原版保留

按阶段切换

MCTS 探索中前盘，剩余 ≤12 空格后切换 Alpha-Beta。

发现的问题：短时间内终局模拟不足；到残局才切换，无法修复前期已经失去的局面。

混合的是两种搜索算法的使用阶段。仍可选择和复现实验。

V2 / 搜索机制组合

把预算用在关键分支

PVS 主变化搜索＋置换表＋历史与杀手着排序＋迭代加深。保留基线评估函数。

改进方向：复用重复局面，让更可能好的着法先搜索；后续分支先做零窗口验证，必要时完整重搜。

同深度最佳分数与基线等价，优势来自同时间内完成更多搜索。

V3 / 动态评估组合

搜索与局面特征协同

在 V2 上加入动态角邻格价值、潜在行动力、阶段性前沿子与子数权重，并用愿望窗口加速搜索。

改进方向：区分空角旁危险格与已占角旁可用格，重视未来落点与棋形；不只追求当前子数。

经典方法的自主实现与组合，不将 PVS 等已有技术宣称为原创。
